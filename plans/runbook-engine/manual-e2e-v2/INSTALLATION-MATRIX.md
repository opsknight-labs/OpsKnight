## 1. Executive Summary & Installation Methods Tested

This matrix verifies the installation, execution, restart identity persistence, and upgrade lifecycle across all supported deployment methods:

1. **Direct Docker Run** (Standalone single container with named volume)
2. **Docker Compose** (Multi-container declarative deployment)
3. **Helm Chart** (Kubernetes enterprise packaging)
4. **Kustomize** (Kubernetes declarative overlay)
5. **Native Linux Systemd** (Direct host daemon)
6. **Rootless Podman** (Unprivileged user namespace & socket)
7. **Docker Swarm** (Orchestrated stack service)
