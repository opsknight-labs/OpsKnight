# Troubleshoot integrations

Use [Integration webhook is rejected](./webhook-rejected) for authentication, signature, schema, size, or rate-limit failures. Preserve the provider delivery ID, timestamp, HTTP status, response body, target integration, and a redacted payload; never paste the webhook secret into a ticket.
