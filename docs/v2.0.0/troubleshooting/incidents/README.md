# Troubleshoot incident processing

Use [Incident lifecycle action is stuck](./lifecycle-stuck) when acknowledge, assign, escalate, resolve, or related processing does not converge. Record the incident ID, attempted action, timestamp, actor, UI/API result, worker health, and relevant logs.
