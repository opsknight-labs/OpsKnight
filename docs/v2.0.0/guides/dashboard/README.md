# Command Center

The Command Center at `/` is the signed-in operational home page. It combines
current incident state, responder work, service risk, on-call context, SLA
warnings, and time-window metrics. It is an operational view; use **Analytics**
for deeper historical analysis and **Reports** for saved executive dashboards.

Start with [Use the Command Center](./use-command-center) for a complete tour of
scope, metrics, response panels, live behavior, exports, and troubleshooting.
