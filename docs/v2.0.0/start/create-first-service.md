# Create your first service

## Before you begin

Sign in as an administrator and create or select an ownership team.

## Create the service

1. Open **Services**.
2. Select **Create service**.
3. Enter a recognizable service name and description.
4. Assign the ownership team.
5. Save the service.

Open the service detail page and confirm its ownership. Next, either
[configure on-call](./configure-on-call) or [receive your first alert](./receive-first-alert).
