# Team administration tasks

Teams group responders for service ownership, access, and collaboration. Follow
[Create and manage a team](./manage-team), then review the [Teams concept](../../concepts/teams)
for authorization and relationship details. SCIM Groups can also synchronize
teams and membership; decide which system is authoritative before editing both.
