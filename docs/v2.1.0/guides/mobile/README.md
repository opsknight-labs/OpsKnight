# Mobile and PWA

Begin with [installation and Push](./install-and-notifications), then practice
[incident response](./respond-to-incidents) on a test incident. Review
[mobile operations](./use-mobile-operations) for navigation and supported
actions, and [offline behavior and updates](./offline-and-updates) before relying
on the installed PWA during an incident. Push registration is per device and is
separate from the lifetime of an interactive login session.
