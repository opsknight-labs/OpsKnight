# Standalone runbook Agent

This chart deploys only the runbook Agent and its policy, ServiceAccount and persistent identity storage. It connects to an existing OpsKnight installation; it does not deploy the application, PostgreSQL, or migrations.

Create the namespace before the enrollment Secret, then use the Helm command generated by **Runbooks → Agents → Add Agent**. Set `agent.url` to an Agent-reachable OpsKnight URL and `agent.enrollmentToken.existingSecret` to the enrollment Secret. Secret-backed steps require HTTPS. The Secret contains `OPSKNIGHT_AGENT_ENROLLMENT_TOKEN` and `OPSKNIGHT_EXECUTION_PUBLIC_KEY`.

The default local policy allows only limited Linux diagnostics, with no Kubernetes API permissions or service-account token. Configure narrowly scoped `agent.policy` and `agent.rbac.rules` for approved operations. This standalone chart does not install a NetworkPolicy: apply an environment-specific policy allowing the configured OpsKnight endpoint and approved targets.

Use one replica and preserve the PVC. Enrollment is single-use; restarts authenticate with the identity on the PVC. Keep the referenced Secret present. Use separate release names and `fullnameOverride` values for distinct Agents in the same namespace.
