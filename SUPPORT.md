## 🛡️ Security Vulnerability Reporting

If you have identified a potential security vulnerability in OpsKnight:

> **Important**: Do **not** disclose vulnerabilities or exploit material via public GitHub issues, discussions, or pull requests.

Please follow our [Security Policy](SECURITY.md):

1. **Private GitHub Advisory (Preferred)**: Submit a private report via GitHub's [Private Vulnerability Reporting Form](https://github.com/opsknight-labs/OpsKnight/security/advisories/new).
2. **Direct Contact**: Contact [help@opsknight.com](mailto:help@opsknight.com) with the subject line `Private security report`. Request a secure communication channel before transmitting sensitive material or reproduction artifacts.

**Response Targets**:

- Maintainers aim to acknowledge reports within **two business days** and provide an initial assessment within **five business days**.
- See [SECURITY.md](SECURITY.md) and the [Vulnerability Response Plan](docs/security/vulnerability-response.md) for full triage, patching, and coordinated disclosure procedures.
